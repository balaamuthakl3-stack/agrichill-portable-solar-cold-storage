Portable Solar Mini Cold Storage System

Project Description

I developed a low-cost, portable, solar-powered mini cold storage system designed to help rural farmers preserve fresh vegetables, especially in remote areas of North-East India.

Problem Statement

Farmers in remote areas face difficulties preserving fresh vegetables due to limited cold-storage facilities, unreliable electricity, and transportation challenges.

Proposed Solution

This project uses solar energy, an ESP32 microcontroller, temperature and humidity sensors, and a Peltier cooling unit to monitor and control storage conditions.

Key Features

- Portable and compact design
- Solar-powered operation with rechargeable battery support
- Temperature and humidity monitoring
- Automatic cooling control
- Designed for rural and remote agricultural applications

Hardware Components

- ESP32
- DS18B20 temperature sensor
- DHT11 sensor
- Peltier cooling kit
- Solar panel
- Rechargeable battery
- Solar charge controller
- Insulated storage box
- LCD display, LEDs, and buzzer

Expected Outcome

A working hardware prototype demonstrating portable cooling, environmental monitoring, and solar-assisted power for small-scale vegetable storage.
