#Hardware Components

Project: Portable Solar Mini Cold Storage System

Main Components

- ESP32 microcontroller
- DS18B20 temperature sensor
- DHT11 temperature and humidity sensor
- Peltier cooling kit
- Solar panel
- Rechargeable battery
- Solar charge controller
- Insulated storage box
- 16x2 I2C LCD
- LEDs and buzzer
- Reed switch
- Voltage sensor
- Cooling fans

Main Features

- Portable mini cold-storage design
- Solar-assisted power supply
- Temperature and humidity monitoring
- Cooling control
- Local status indication and alerts

Application

Designed for small-scale farmers in rural and remote agricultural areas.
